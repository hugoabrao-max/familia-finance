Instalar o Family Finance

Siga os passos na ordem. Tudo fica nas suas contas: ninguém mais tem acesso. Leva cerca de 40 minutos. Esta página guarda o que você preencher, pode fechar e voltar depois.

1Crie duas contas (grátis)

  1. Supabase: é o banco de dados e o login do app. Pode entrar com a conta do Google ou do GitHub, ou com e-mail.
  2. Netlify: é onde o app fica no ar. Pode entrar com o Google.

A conexão com o seu banco (Pluggy) fica para o final.

2Seus dados

3Crie o banco de dados

  1. Abra Supabase → New project.
  2. Em Project name, escreva family-finance.
  3. Em Database Password, clique em Generate a password e guarde essa senha num lugar seguro.
  4. Em Region, escolha South America (São Paulo).
  5. Clique em Create new project e espere uns 2 minutos, até sumir o aviso de "setting up".
  6. Na tela do projeto aparece o Project URL (algo como https://abcdefghij.supabase.co). Se não aparecer, clique em Connect no topo. Copie e cole aqui:

4Monte o banco

Você vai colar dois textos no editor de SQL do Supabase e clicar em Run.

  1. Abra o editor de SQL do seu projeto.
  2. Clique na área de texto do editor, cole com Ctrl+V e clique em Run (ou Ctrl+Enter). Se aparecer um aviso perguntando se quer mesmo rodar, confirme. Deve aparecer Success. No rows returned.
  3. Apague o texto do editor (Ctrl+A e Delete). Cole e clique em Run.
  4. Para conferir: apague, , cole e rode. Deve mostrar 48 categorias e 1 pessoa.
Se der erro na parte 1, não rode de novo por cima: me mande um print do erro.

5Publique as funções

São 3 funções. Para cada uma:

  1. Abra Edge Functions → Deploy a new function → Via Editor.
  2. No nome da função (no alto ou embaixo do editor), escreva exatamente o nome da lista abaixo.
  3. Apague todo o código de exemplo do editor, copie o código da função aqui e cole lá.
  4. Clique em Deploy function.
  5. Depois de publicada, abra a função → aba Details (ou Settings) → desligue a opção Verify JWT (às vezes chamada de "Enforce JWT verification") → Save changes.

7Coloque o app no ar (Netlify)

  1. Na pasta Downloads, clique com o botão direito em family-finance-app.zip → Extrair tudo → Extrair. Vai aparecer a pasta family-finance-app.
  2. Já logado na Netlify, abra app.netlify.com/drop.
  3. Arraste a pasta family-finance-app para a área indicada na página e espere terminar.
  4. Vai aparecer um endereço terminado em .netlify.app. Se quiser um nome mais bonito: Site configuration → Change site name.
  5. Copie o endereço final e cole aqui:

Para atualizar o app no futuro: em Deploys, arraste a pasta nova para a área "Drag and drop". O endereço não muda.

8Configure o login

  1. Abra Authentication → URL Configuration.
    • Em Site URL, cole e salve.
    • Em Redirect URLs → Add URL, cole e salve.
  2. Abra Edge Functions → Secrets. Em Name escreva APP_URL ; em Value cole . Clique em Save.
  3. Abra Authentication → Users → Add user → Create new user.
    • E-mail: (tem que ser o mesmo do passo 2).
    • Senha: crie a senha que você vai usar para entrar no app.
    • Deixe marcado Auto Confirm User → Create user.
  4. Abra Authentication → Sign In / Providers e desligue Allow new users to sign up → Save. Assim, só entra quem você cadastrar.
  5. Para conferir, no editor de SQL: , cole e rode. A coluna login_ligado deve mostrar true.

9Agendamentos

Faz o app buscar os dados do banco 4 vezes por dia e mandar o aviso diário no celular.

  1. No editor de SQL: , cole e clique em Run.

10Abra o app

  1. Abra o seu app e entre com o e-mail e a senha do passo 8.
  2. No celular, abra o mesmo endereço e adicione à tela de início:
    • iPhone: Safari → Compartilhar → Adicionar à Tela de Início.
    • Android: Chrome → menu (⋮) → Adicionar à tela inicial.
  3. Para receber avisos de lançamentos a classificar: no app, Mais → Notificações → Ligar neste aparelho → Enviar teste. No iPhone, isso só funciona abrindo pelo ícone da tela de início.
  4. Pessoas da família: cadastre em Mais → Membros.

O app vai estar vazio até você conectar o banco, no próximo passo.

11Conecte seu banco (Pluggy)

Faça você mesmo, por último. É a única parte que mexe com seus dados bancários.

  1. Crie a conta em dashboard.pluggy.ai e crie uma aplicação. Anote o Client ID e o Client Secret. Confira o plano na Pluggy.
  2. Conecte suas contas pelo Meu Pluggy, conforme a Pluggy orientar, e anote o id do item conectado (um código longo, com hífens).
  3. Abra Edge Functions → Secrets e crie dois segredos: PLUGGY_CLIENT_ID e PLUGGY_CLIENT_SECRET , cada um com o valor da Pluggy. Esses valores vão só lá: não cole em nenhum outro lugar.

A primeira sincronização acontece no próximo horário agendado (21:15, 23:15, 06:15 ou 18:15, horário de Cuiabá). Os lançamentos aparecem no app; classifique em Revisão e marque "criar regra" para o app aprender.

A Pluggy atualiza os dados do banco cerca de uma vez por dia. O cálculo da fatura do cartão foi conferido com um cartão Santander; em outro banco, confira as primeiras faturas com o PDF.
